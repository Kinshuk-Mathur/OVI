# Editable voice transcription

A microphone click opens a permission request. An AudioWorklet batches mono PCM from a 16 kHz AudioContext. The browser flushes its last partial block on Stop and produces a canonical 16-bit WAV. A timer stops capture at two minutes, and the sample writer independently caps output size. Cancellation stops the media tracks and closes the audio context. Recording requires HTTPS or a supported localhost origin and a browser with AudioWorklet support.

The transcription route verifies identity, bounds bytes while reading, validates the RIFF and PCM fields and derives duration from the actual payload length. A 120-second clip is 3,840,044 bytes. Neither a caller duration nor an arbitrary compressed media header authorizes a charge. The user pays whole seconds rounded upward. Shared hourly and daily audio budgets reserve at least ten seconds per request to account for Groq's minimum billed length. The browser's format is below Groq's documented free-tier file limit. [Speech-to-text documentation](https://console.groq.com/docs/speech-to-text)

The function uploads the bytes to `audio/transcriptions` using `whisper-large-v3-turbo`. It leaves language detection to the provider and supplies a stable hint to preserve the spoken words when a speaker switches languages. The user can edit, discard or send the returned text. Recordings and transcripts are transient until the user explicitly sends a chat message. Microphone denial, failed transcription and exhausted voice quota leave typing available.
